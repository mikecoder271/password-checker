# 🔒 Secure Password Strength Analyzer

An interactive, client-side web application that evaluates password strength and character requirements in real time. Built as a portfolio project for the **INSA Weekend Program (Cyber Talent Center)** track selection.

## 🚀 Live Demo
You can test the live application here: **https://mikecoder271.github.io/password-checker**

## 🛡️ Security Feature
* **100% Client-Side:** No data is sent to an external server or database. All password analysis is processed entirely locally within your browser using vanilla JavaScript regex patterns.

## 📋 Evaluated Criteria
The analyzer grades passwords based on modern cybersecurity practices:
* **Length Check:** Ensures the password is at least 8 characters long.
* **Casing:** Validates the presence of uppercase (`A-Z`) characters.
* **Numeric Value:** Detects numerical values (`0-9`).
* **Special Characters:** Flags symbols (e.g., `!@#$%^&*`) to calculate complexity scores.

## 🛠️ Tech Stack Used
* **HTML5:** Semantic document markup.
* **CSS3:** Responsive user card interface with smooth CSS transitions for the visual meter bar.
* **JavaScript:** Live keyup event checking and regex pattern mapping.
